Here is the step-by-step guide:
1. Prerequisites
Ensure you have Node.js installed. You can download it from nodejs.org.
2. Create the Project
Open your terminal (Command Prompt or VS Code Terminal) and run the following commands:

npm create vite@latest game-sage-hub -- --template react-ts

# Navigate into the folder
cd game-sage-hub

# Install the required dependencies used in the code
npm install react-router-dom lucide-react @google/genai


3. Organize the Files
Open the game-sage-hub folder in VS Code (code .).
Inside the src/ folder, delete the default files (like App.css, App.tsx, index.css, etc.) but keep main.tsx (or index.tsx) and vite-env.d.ts.

4. Important: Fix the API Key
Vite handles environment variables differently than the provided code (process.env).
Create a file named .env in the root folder (next to package.json).
Add your Gemini API Key:
code
Env
VITE_API_KEY=your_actual_api_key_here
Update src/services/geminiService.ts:
Change this line:
code
TypeScript
// Old
const apiKey = process.env.API_KEY || 'YOUR_API_KEY_HERE';

// New (Vite compatible)
const apiKey = import.meta.env.VITE_API_KEY || 'YOUR_API_KEY_HERE';
5. Run the App
Back in your terminal, run:

Bash

VS Code will provide a localhost link (usually http://localhost:5173). Ctrl+Click that link to open your Game Sage Hub in the browser.



 Where to place Image Files & How to import them
For a data-heavy file like src/data.ts, importing images one by one (e.g., import img from './assets/img.png') can make the file very cluttered. The best approach is to use the Public Folder method.
Step 1: Place the Files
Create a folder named public in your project root if it doesn't exist.
Inside public, create a folder named images.
Drop your character/weapon images there (e.g., mualani.jpg, kinich.png).
Step 2: Reference them in data.ts
You can refer to files in the public folder using absolute string paths. You do not need to use the import keyword.
Update your src/data.ts like this:
code
TypeScript
// Old way (Placeholder)
// image: getImg(150, 150, 'mualani'),

// New way (Local File)
// Assuming you put mualani.jpg inside public/images/
image: '/images/mualani.jpg',
Example Update for src/data.ts:
code
TypeScript
export const genshinCharacters: Character[] = [
  {
    id: 'mualani',
    name: 'Mualani',
    rarity: Rarity.FIVE_STAR,
    element: 'Hydro',
    weaponType: 'Catalyst',
    // Path starts with / which points to the public folder
    image: '/images/mualani.jpg', 
    detailImage: '/images/mualani-full.jpg',
    description: '...',
    moreDetailsUrl: '...'
  },
  // ... other characters
];
This method keeps your data.ts clean and makes it easy to manage hundreds of images.
